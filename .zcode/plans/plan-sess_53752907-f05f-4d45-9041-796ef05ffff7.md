# RGBD 深度图畸变校正模块 — 实现计划

## 目标
在 Splatshop 中新增一个"相机标定与畸变校正"GUI 模块，通过实时采集棋盘格标定板图像，优化 Orbbec RGBD 相机的径向/切向畸变参数（参考 OpenCV `calibrateCamera`），并把校正结果用于：(1) 持久化到本地标定 JSON 文件，(2) Orbbec Preview 的实时去畸变预览，(3) 替换点云生成的内参/畸变参数使 RGB 点云几何更准确。支持 Color / IR / Depth 三个流的标定。

## 设计决策（已与用户确认）
- **引入 OpenCV**（`find_package(OpenCV)`），仅在标定模块编译时链接；运行时去畸变用预计算映射（`cv::initUndistortRectifyMap` → LUT），不上传到 CUDA，避免影响预览管线依赖。
- 标定目标：**Color + IR + Depth** 三流。IR 流需在 `OrbbecCapture` 新增采集支持；Depth 流通过 IR 流标定（深度传感器与 IR 同源，棋盘格在 IR 图上可见）后共享畸变参数。
- 采集方式：**实时连续采集**（实时预览 + 自动/手动捕获棋盘格位姿）。
- 参数输出：**保存本地 JSON + 实时去畸变预览 + 应用到点云内参**。

## 详细实现

### 1. CMake / OpenCV 集成（`cmake/opencv.cmake`，仿 `orbbec.cmake` 模式）
- `ADD_OPENCV(TARGET)`：`find_package(OpenCV REQUIRED COMPONENTS core calib3d imgproc highgui)`（不要求 highgui，仅 core+calib3d+imgproc）。
- 找到则定义 `SPLATSHOP_HAS_OPENCV=1` 并 `target_link_libraries(${TARGET} ${OpenCV_LIBS})`；找不到则 `message(WARNING ...)` 并 return，标定面板编译为空 stub（与 Orbbec 的可选模式一致）。
- 在 `CMakeLists.txt` 中：`include(cmake/opencv.cmake)` + `ADD_OPENCV(${TARGET_NAME})`，放在 `ADD_ORBBEC` 之后。
- 新增 `file(GLOB ... src/calibration/*.*)` 到源文件列表。

### 2. 标定数据结构（`include/Calibration.h`，纯数据，无 SDK 依赖）
```cpp
struct DistortionCoeffs { float k1,k2,p1,p2,k3; };  // 5 参数 Brown-Conrady
struct StreamCalibration {
    orbbec::Intrinsics intrinsics;      // fx,fy,cx,cy,w,h（标定结果）
    DistortionCoeffs distortion;
    double rmsReprojectionError;
    int usedImageCount;
    std::string timestamp;              // ISO 时间
    bool valid = false;
};
struct DeviceCalibration {
    std::string deviceSerial;
    std::string deviceName;
    StreamCalibration color, ir, depth;   // depth 复用 ir 的畸变（同源）
    std::string notes;
};
// JSON 序列化：to_json / from_json（nlohmann，仿 SplatsyFilesLoader 的 using json 模式）
```

### 3. 标定引擎（`src/calibration/Calibrator.{h,cpp}`，依赖 OpenCV）
- `class Calibrator`，状态：棋盘格规格（cols, rows, squareSize_mm）、采集到的标定图像 `vector<cv::Mat>` + 角点、标定结果。
- 方法：
  - `setChessboard(int cols, int rows, float squareSizeMm)`
  - `bool detectAndAddFrame(const cv::Mat& img)` — `cv::findChessboardCornersSB`（改进型，更鲁棒）+ `cv::cornerSubPix` 亚像素细化；返回是否成功检测到棋盘格（供 GUI 实时高亮提示）。
  - `bool addDetectionOnly(...)` — 仅检测不存储（用于实时预览高亮，不计入样本）。
  - `double runCalibration(StreamCalibration& out)` — 构造 objectPoints（Z=0 平面）、`cv::calibrateCamera`（flags: `CALIB_RATIONAL_MODEL` 关闭以限定为 k1,k2,p1,p2,k3），返回 RMS 重投影误差。
  - `void computeUndistortMaps(const StreamCalibration& cal, cv::Mat& mapX, cv::Mat& mapY)` — `cv::initUndistortRectifyMap`，分辨率与 cal 匹配；缓存避免每帧重算。
  - `void undistort(const cv::Mat& src, cv::Mat& dst, const StreamCalibration& cal)` — `cv::remap` 用缓存 LUT。
  - `const vector<cv::Mat>& sampleImages() const` — 供 GUI 显示缩略图。
  - `void clear()`。

### 4. 标定文件存储（`src/calibration/CalibrationStore.{h,cpp}`）
- 文件路径：`./calibration/<serial>_<resolution>.json`（与可执行文件同级目录，仿 OrbbecSDKConfig.xml 落位习惯）。
- `bool save(const DeviceCalibration&, const std::string& path)`
- `bool load(DeviceCalibration&, const std::string& path)`
- `bool loadForDevice(DeviceCalibration&, const std::string& serial, int w, int h)` — 按 SN+分辨率查找。
- 使用 `libs/json/json.hpp`（nlohmann），仿 `SplatsyFilesLoader.h` 的 `using json = nlohmann::json`。

### 5. OrbbecCapture 扩展（IR 流 + 畸变读取 + 外部标定应用）
`OrbbecTypes.h`：
- `StreamConfig` 已通用，IR 复用即可（在 `CameraParams` 或新增 `StreamConfig irCfg`）。
- `RGBDFrame` 新增 `irData / irWidth / irHeight / irFormat` 字段（可选，仅 IR 启用时填充）。
- `Intrinsics` 旁新增 `DistortionCoeffs`（已在 Calibration.h，OrbbecTypes 引用）。

`OrbbecCapture.h/.cpp`：
- `start()` 中按 `impl->cfgIR.enable` 调 `config->enableVideoStream(OB_STREAM_IR, ...)`。
- `captureLoop()` 中 `frameSet->getIrFrame()` 拷贝到 `RGBDFrame::irData`。
- 新增 `getIrIntrinsics()` / `getColorDistortion()` / `getDepthDistortion()` / `getIrDistortion()`：调用 `VideoStreamProfile::getDistortion()`（SDK 已提供，当前未用），把 `OBCameraDistortion.k1,k2,p1,p2,k3` 填入 `DistortionCoeffs`（按 `OBCameraDistortionModel` 甄别，仅 Brown-Conrady 系列直接采用）。
- 新增 `setExternalCalibration(const DeviceCalibration&)`：缓存外部标定，供预览/点云使用（不写回设备固件，避免不可逆；写设备留作后续可选）。
- 新增 `getEffectiveColorIntrinsics()` 等：返回外部标定（若已加载）否则设备内参。

### 6. GUI 标定面板（`src/gui/orbbec_calibration.h`）
仿 `orbbec.h` 的面板结构。窗口标题 "Orbbec Calibration"，`#ifdef SPLATSHOP_HAS_ORBBEC && SPLATSHOP_HAS_OPENCV`。

布局（CollapsingHeader 分节）：
- **Chessboard Settings**：列数/行数（内角点）、方格尺寸(mm) 输入；标定目标流 Combo（Color/IR/Depth）。
- **Live Capture**：
  - 实时显示当前流的小预览图（复用 `orbbec_preview.h` 的纹理上传逻辑的精简版，或直接显示 OpenCV 检测结果叠加图）。
  - 自动检测开关：开启时每帧调用 `detectOnly`，检测到棋盘格则在预览上绘制角点连线（绿色）并提示 "Valid pose ✓"；满足位姿多样性时自动捕获（或用户点 "Capture" 手动）。
  - 采集计数显示 "N / M (建议≥15)"。
  - 按钮：Capture / Auto-capture toggle / Clear samples / Remove last。
  - 采样缩略图条（最近 6 张，点击可放大）。
- **Run Calibration**：按钮 "Calibrate" → 调 `runCalibration`；显示 RMS 误差、fx/fy/cx/cy/k1..k3 结果；与设备原始内参对比表。
- **Persistence**：Save to file / Load from file / "Apply to device calibration"（载入到 `OrbbecCapture::setExternalCalibration`）；显示当前已加载标定文件路径与时间戳。
- **Apply / Preview**：
  - Checkbox "Undistort preview" — 让 Orbbec Preview 面板实时去畸变。
  - Checkbox "Use calibrated intrinsics for point cloud" — 让点云路径使用标定内参。
  - 复用 LUT：分辨率变化时重算。

实时去畸变预览的实现策略（性能考量）：
- 方案：在 `Orbbec_capture` 预览帧上传 GL 纹理**之前**，于 CPU 端用缓存的 `mapX/mapY` 调 `cv::remap`（uint16 深度用 `INTER_NEAREST` 避免深度插值伪值；彩色用 `INTER_LINEAR`）。由于预览本身已是 CPU 端处理管线（colormap LUT、格式转换都在 CPU），多一步 remap 不破坏架构，且标定面板关闭时不产生开销。
- 在 `orbbec_preview.h` 中加一个 `if (settings.orbbecUndistortPreview && calValid)` 分支：先 `Calibrator::undistort(...)` 再走原有上传路径。LUT 在标定完成/分辨率变化时计算一次。

## 算法要点（参考 OpenCV）
- 角点检测：`cv::findChessboardCornersSB(img, patternSize, corners, CALIB_CB_NORMALIZE_IMAGE + CALIB_CB_EXHAUSTIVE)`，失败时回退 `findChessboardCorners` + `cornerSubPix`（winSize 11x11）。
- 标定：`cv::calibrateCamera(objectPoints, imagePoints, imageSize, cameraMatrix, distCoeffs, rvecs, tvecs)`，初始 `cameraMatrix = cv::initCameraMatrix2D`；不设 `CALIB_RATIONAL_MODEL`（保持 5 参数 k1,k2,p1,p2,k3）；可选 `CALIB_FIX_ASPECT_RATIO` 由用户开关。
- 误差评估：RMS 重投影误差；每张图单独误差用于剔除离群样本（GUI 显示，>阈值标红可删除）。
- 去畸变映射：`cv::initUndistortRectifyMap(K, dist, cv::noArray(), K_new, size, CV_16SC2, mapX, mapY)`（`K_new` 默认取 `cv::getOptimalNewCameraMatrix`，alpha 由用户滑条控制 0-1）。`CV_16SC2` 固定点格式便于 `remap` 高效执行。
- 深度流畸变：直接用 IR 的畸变参数（深度传感器与 IR 物理同源）；深度值重映射用最近邻，不引入虚假深度值。

## 降级与安全
- OpenCV 找不到：标定面板为空 stub，其余 Orbbec 功能不受影响。
- 未标定：去畸变开关不可用（灰显），点云沿用设备内参。
- 写设备固件：本期**不实现**（避免不可逆；仅缓存外部标定用于软件侧校正），在 GUI 标注 "software-side only"。
- 标定文件损坏：JSON 解析失败时 warning，回退到设备内参。

## 验证方式
- CMake 配置阶段打印 OpenCV 版本与是否启用标定模块。
- 构建 SplatEditor，启动后菜单出现 "Calib" 按钮。
- 连接 Orbbec 设备，开启 IR/Color 流，用棋盘格标定板采集 ≥15 张不同位姿，执行标定，检查 RMS < 1.0 像素。
- 开启 "Undistort preview"，确认直线条（如门框/标定板边缘）在去畸变后变直。
- 保存/重新加载 JSON 标定文件，数值一致。
- 开启 "Use calibrated intrinsics for point cloud"，确认点云几何更平直。

6. `orbbec_preview.h` 去畸变分支。
7. 点云内参替换路径。
