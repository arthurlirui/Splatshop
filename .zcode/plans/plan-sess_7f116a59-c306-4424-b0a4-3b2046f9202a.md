## 安装搜索 MCP Server 计划

### 前置检查
1. 检查 Python 3.12+ 是否已安装（`python --version`）
2. 检查 uv 是否已安装（`uv --version`），如未安装则引导安装

### 配置修改
3. 读取 `~/.zcode/cli/config.json` 当前内容
4. 在 `config.json` 中添加 `mcp.servers` 配置项，配置 `mcp-server-askecho-search-infinity` MCP Server：
   - 使用 `uvx` 命令从 GitHub 仓库安装
   - 环境变量中预留 AK/SK 和 API Key 字段（需用户自行填入）
5. 保存配置文件

### 鉴权说明
- AK/SK 和 API Key 二选一即可
- 用户需自行填入敏感凭据，Agent 不代为填写
